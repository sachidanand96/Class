# Join Me Commerce Classes — Jule Solapur Branch
## Premier Commerce Coaching Web Portal

Official responsive web portal concept designed for **Join Me Commerce Classes** (Jule Solapur Branch, Solapur, Maharashtra, India), under the academic leadership of **Prof. Pradeep Bhandare Sir**.

---

## 📚 Programs & Courses Offered

- **11th Commerce (HSC - FYJC):** Foundational mastery in double-entry bookkeeping, microeconomics, OCM, and SP.
- **12th Commerce (HSC - SYJC):** Maharashtra State Board exam preparation with scoring blueprints and preliminary tests.
- **CA Foundation (ICAI):** Specialized coaching across Paper 1 (Accounting), Paper 2 (Business Laws), Paper 3 (Quantitative Aptitude), and Paper 4 (Business Economics).
- **B.Com & BBA:** Degree subject support for undergraduate commerce and management students.

## 🛠️ Technology Stack

- **Framework:** React 18 with TypeScript
- **Bundler:** Vite
- **Styling:** Tailwind CSS (Custom palette: Sovereign Navy, Warm Ivory, Heritage Emerald, Antique Gold)
- **Typography:** Playfair Display (Serif display) + Plus Jakarta Sans (Clean UI body)
- **Icons:** Lucide React
- **SEO & Structured Data:** Schema.org `EducationalOrganization` & `LocalBusiness` JSON-LD

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
